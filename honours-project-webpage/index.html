The question: Can experience from previous AI generation runs be converted into reusable beliefs that improve later runs?

At a glance

Turn completed AI runs into guidance for the next one.

Design and evaluate a memory system that converts recorded generation experience into reusable guidance, then test whether it improves efficiency, whether timing matters, and whether the guidance transfers to unseen topics.

In plain language

A belief is a reusable natural-language instruction supported by execution evidence. For example, a general lesson learned from a successful code repair.

Why it matters: avoiding repeated work can reduce model usage, latency and computational cost.

01 · The problem

AI agents solve a problem, then forget the experience.

Modern AI systems can plan, write code, test it and repair errors. Yet useful lessons often disappear when a run ends.

That matters for structured animation generation: producing an educational video requires many linked decisions about narration, visual layout, timing, code and debugging. Similar failures can recur across different topics, wasting computation and limiting improvement.

i

Structured animation code describes editable objects and actions that are rendered deterministically into video, unlike directly generated pixels.

The project extends Code2Video with agents that leave structured execution traces, plus a pipeline that converts those traces into beliefs and selects relevant guidance for later runs.

04 · Significance

Why this matters

Generative AI is computationally expensive and often repeats its mistakes. Reusing validated experience could make agentic systems more efficient, auditable and capable of cumulative improvement.

↓

Lower computational cost

Fewer generated tokens can reduce cost, energy use and response latency at scale.

◎

More accountable guidance

Beliefs retain evidence and contradiction histories instead of acting as opaque prompt additions.

↗

Transferable experience

Lessons that generalise across topics provide a path towards systems that improve over time.

05 · Conclusion

What the project established and what remains unproven.

Established

AI generation experience can become useful reusable guidance.

  • Built an evidence-backed memory layer for Code2Video.
  • Reduced token use within known and unseen topic batches.
  • Found that targeted reactive guidance outperformed broader injection.
Not yet established

The evidence does not show a general quality improvement.

  • No reliable improvement in time, aesthetics or TeachQuiz gain.
  • Most topic-condition pairs were generated only once.
  • Human evaluation is still required to validate perceived quality.

06 · Next steps

What comes next?

Four independent research priorities would strengthen the evidence, selection process, memory system and evaluation.

↻Reliability

Repeat stochastic runs

Measure within-topic variability, not only variation across the 90 topics.

◎Selection

Learn selection weights

Replace fixed heuristic coefficients and thresholds with values learned from evidence.

⟳Memory

Continuously refine memory

Update an existing belief base as new evidence arrives instead of rebuilding it.

✓Validation

Add human evaluation

Validate whether educators and learners agree with automated quality assessments.
